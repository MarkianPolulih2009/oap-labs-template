## Завдання 1. Трикутник за трьома сторонами

### Постановка задачі

За сторонами трикутника `a`, `b`, `c` обчислити:

- півпериметр `p = (a + b + c) / 2`;
- площу за Героном `S = sqrt(p * (p - a) * (p - b) * (p - c))`;
- радіус вписаного кола `r = S / p`;
- радіус описаного кола `R = a * b * c / (4 * S)`;
- висоту до сторони `a`: `h = 2S / a`.

### Тести

| Вхід | Очікуваний результат |
|---:|---|
| `3 4 5` | `p = 6.00`, `S = 6.00`, `r = 1.00`, `R = 2.50`, `h = 4.00` |
| `1 1 1` | `p = 1.50`, `S = 0.43`, `r = 0.29`, `R = 0.58`, `h = 0.87` |

### Обмеження та перевірка

У формулі для площі за Героном потрібна умова, щоб три числа були сторонами справжнього трикутника: `a + b > c`, `a + c > b`, `b + c > a`, а також `p > 0`.

## Завдання 2. Варіант 16

### Постановка задачі

Обчислити:

`s = (sqrt(x) + cbrt(y)) / (1 + |z|)`

де `x`, `y`, `z` — введені значення.

### Обмеження на вхід

Для формули випливають такі умови:

- `x >= 0`, бо під коренем стоїть `sqrt(x)`;
- `1 + |z| != 0`, але для будь-якого дійсного `z` цей вираз завжди більше нуля;
- `cbrt(y)` визначено для будь-якого дійсного `y`, тому обмежень на `y` немає.

### Псевдокод

```text
початок
    ввести x, y, z
    sqrtTerm := sqrt(x)
    cbrtTerm := cbrt(y)
    denominator := 1 + abs(z)
    s := (sqrtTerm + cbrtTerm) / denominator
    вивести x, y, z, s
кінець
```

### Тести

| Вхід (`x y z`) | Очікуваний `s` |
|---:|---:|
| `9 -8 -3` | `0.2500` |
| `0 0 0` | `0.0000` |
| `4 8 1` | `2.0000 + 2.0000 / 2 = 2.0000` |

### Результат

Для контрольного прикладу `x = 9`, `y = -8`, `z = -3` значення:

`s = (3 + (-2)) / (1 + 3) = 1 / 4 = 0.25`.

## Завдання 3. Практична задача (варіант 16)

### Постановка задачі

Вхідні дані: напруга `U`, струм `I`, час `t` (год), тариф `rate` (грн/кВт·год).  
Потрібно обчислити:

- потужність `P = U * I` (Вт);
- енергію `W = P * t / 1000` (кВт·год);
- вартість `cost = W * rate` (грн).

### Тести

| Вхід (`U I t rate`) | Очікуваний результат |
|---:|---|
| `220 5 3 4.32` | `1100 W`, `3.300 kWh`, `14.26 UAH` |
| `0 5 3 4.32` | `0 W`, `0.000 kWh`, `0.00 UAH` |

## Висновок

У програмі використано функції з бібліотеки `<cmath>`:

- `std::sqrt` — для квадратного кореня;
- `std::cbrt` — для кубічного кореня;
- `std::fabs` — для абсолютного значення числа.

Тести підтвердили коректність формул для основного прикладу та межового випадку. Найбільшу увагу варто приділяти перевірці припустимих значень вхідних даних (позитивних значень для трикутника, невід'ємного аргумента кореня та відсутності ділення на нуль).
