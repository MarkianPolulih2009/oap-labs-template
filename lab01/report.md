## Мета роботи

Перевірити налаштування середовища розробки, скомпілювати та запустити
готову програму-візитівку зі своїми даними.

## Середовище

- операційна система: Windows;
- компілятор: g++ 16.1.0 (MSYS2);
- стандарт мови: C++17;
- параметри компіляції: `-std=c++17 -Wall -Wextra -pedantic`;
- редактор: Visual Studio Code.

## Хід роботи

1. Створено файл `lab01/main.cpp`.
2. У програму внесено ім'я, групу та номер варіанта.
3. Програму зібрано командою:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic lab01\main.cpp -o lab01.exe
```

4. Програму запущено командою:

```powershell
.\lab01.exe
```
